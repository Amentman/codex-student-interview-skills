# 审查框架

## 1. 证据标签

| 标签 | 定义 | 可用范围 |
| --- | --- | --- |
| `Fact` | 简历或用户材料明确写明 | 可复述为“简历称/材料显示”，不等于已外部验真 |
| `External` | 经授权后，由可靠外部来源验证 | 标明来源、日期与能证明的边界 |
| `Inference` | 根据已知事实作出的可解释推断 | 必须附推断依据和信心等级 |
| `Open` | 缺失、含糊、冲突或需要候选人/外部材料回答 | 转化为核验问题，不补全成负面事实 |

“简历称为真”和“该事实已被验证”是两件事。没有外部来源时，经历、职位、数字和学历都只是候选人陈述的 `Fact`。

## 2. 学历与专业

检查：院校、学历层级、专业、起止时间、学习形式、多段教育的先后与重叠、证书与岗位的明确要求。

相关性与能力必须分开：

- 专业直接相关：只说明可能具备更直接的知识基础。
- 专业部分相关：说明可迁移知识，再看经历证据。
- 专业不直接相关：不代表能力不足，除非 JD 有合法、明确、必须的专业门槛。

## 3. 时间线与 Gap

1. 使用原文精度记录教育、全职、实习、项目和创业；不自行补月份。`YYYY.MM`、`至今` 和按月的起止区间已足够做月级时长与 Gap 计算；只有年份或日期缺失才标“日期精度不足”。保留原文的“至今”，用资料截止月份计算约月数，不把“至今”改成精确到日的终止日。
2. 月份完整时，计算两段之间未覆盖的完整月。用户未给规则时，在完整时间线中显示所有间断，对连续 3 个及以上完整月的未说明区间列为显著 `Open`。
3. 区分合理并行与冲突：在校实习、兼职项目可合理重叠；两段全职重叠需核验，但不直接判定造假。
4. Gap 只记录长度、简历是否解释、对硬门槛计算的影响和待核验问题。不推测失业、疾病、家庭、婚育或稳定性。

## 4. 逐段经历与项目

对每段工作/项目至少检查：

| 维度 | 要回答的问题 |
| --- | --- |
| 背景 | 解决了什么对象的什么问题？ |
| 角色 | 候选人是主导、共同负责、执行还是协助？ |
| 动作 | 做了哪些可观察的分析、决策、实施或协作？ |
| 边界 | 哪些是个人贡献，哪些是团队或系统结果？ |
| 复杂度 | 规模、约束、难点、异常和取舍是什么？ |
| 结果 | 指标的基线、周期、分母、来源与因果链是否说明？ |
| 可验证性 | 能否通过过程、产物、数据口径或追问验证？ |

评估经验年限时分开“相关经验时长”和“独立承担所需职责的证据时长”。实习、助理和兼职经历按用户给定的岗位口径计算；没有口径时分开呈现，不暗中合并。

## 5. 水分风险

使用三种分类，不输出“造假率”或虚假精确分数：

先区分“流程优先级”和“真实性风险”：

- 学校、日期、项目归属等没写，可能是最高流程优先级，因为它会阻断背景或时间线核对；但仅凭缺失不能标为真实性高风险。
- GPU、售前、行业知识等 JD 核心能力没写，属于岗位证据缺口；可触发定向初筛，但不能直接并入“水分”。
- 只有表达、贡献归属或事实之间存在可指出的薄弱点或矛盾时，才进入下面三类水分风险。

因此，同一问题可以“处理优先级高、真实性风险未知”，不要用一个笼统的红色等级替代性质判断。

### 表达空泛

常见信号：只有“负责/参与/赋能/显著提升”；大量术语但无场景、动作和结果口径。

结论边界：可说“表达证据弱”，不能说“经历必然弱”。

### 贡献归属不清

常见信号：将公司/团队结果直接归于个人；“参与”和“主导”交叉；职级、任期与所称决策权显著不匹配。

结论边界：要求说明本人负责范围、关键决策、团队分工与结果归因。

### 真实性矛盾

常见信号：两段全职时间重叠；同一结果重复放在多段经历；数字、团队规模或职位前后冲突；项目发生时间不在相应工作/学习区间内。

结论边界：记录为“显著待核验矛盾”。只有得到可靠外部证据后，才可使用“不实/造假”。

每个风险条目必须同时包含：简历原文或冲突位置、风险类型、严重度、判断依据、一个可能的无恶意解释、核验问题和可接受的证据。

## 6. 岗位匹配与建议

先把 JD 转为用人方可解释的标准：

- 合法硬门槛：是否满足、明确不满足、未提及。
- 核心能力：每一项都映射到简历事实或 `Open`。
- 加分项：不能反向变成隐性硬门槛。

建议使用以下状态，同时附信心等级：

- `建议推进`：核心要求有较强事实证据，风险可通过正常面试核验。
- `建议定向初筛`：有相关信号，但关键证据缺失，用短轮次问题决定是否继续。
- `待补材料/待确认标准`：缺 JD、日期精度不足或存在会改变结论的重大冲突。
- `建议不推进`：候选人明确不满足用户已给定的合法硬门槛；或简历对核心 JD 标准完全缺乏可用证据，达不到用人方明确的简历初筛门槛；或可靠外部证据已确认重大不实。如属证据不足，理由写为“当前材料不足以支持推进”，不写为“候选人不具备该能力”。

信心等级使用 `高 / 中 / 低`，说明依据，不使用看似精准的百分比。
