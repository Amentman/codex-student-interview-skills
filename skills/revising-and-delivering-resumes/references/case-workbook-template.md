## J. 完成判断

- [ ] 用户点名的来源已实际读取并记录定位。
- [ ] 关键事实无未解决冲突；Open 已显式记录。
- [ ] 原文每个要点都有处置，未静默删除。
- [ ] 两方向共享事实一致、表达分别定向。
- [ ] 每方向 Word/PDF 同母版。
- [ ] Word 在目标 WPS/Word 实机检查。
- [ ] PDF 实际渲染/查看，无红字、批注或内部备注。
- [ ] 用户要求单页时，两者均完整、饱满、可读的一页。
- [ ] 最终目录数量与要求一致；旧版处置有授权，并已通过清单/实际读回证明可恢复。
