# 飞书写入边界与验收

## 先定位，再写入

优先使用 lark-cli。操作相应域前读取当前版本的 `lark-shared`、`lark-wiki`、`lark-doc`；上传附件时再读 `lark-drive` 及相关媒体指南。参数以当前指南和 help 为准，不在 Skill 固化易漂移的命令。

1. 找到唯一学生主页、通用学生版及老师版，确认真实标题和父子关系。用户给出的入口优先；无入口时搜索已有知识库。列表有分页就继续到候选范围完整，不把第一页当全部。
2. 列出通用学生版下的子页，按公司、岗位和职位编号核对已有专岗页，不能只凭一个模糊词匹配。唯一同岗页复用；无匹配才新建；多个可能匹配时只问一个必要问题。
3. 本轮状态中记录通用学生版、老师版与要更新的专岗页的完整 XML、revision_id、章节顺序、附件／媒体标识及手工内容，作为比较依据。原页没有修改授权时保持只读，发现旧规范问题也不能顺手修复。无需持久落盘复制简历或建立学生备份目录。

## 正式写入

- 标准路径：`学生主页 → 姓名｜学生面试准备版 → 专岗准备｜公司｜岗位（编号，如有）`。命名服从用户已明确约定。
- 新岗位准备写进新子页；同岗更新只操作该子页目标章节。默认不更改上级正文，不以导航、便利、首屏可见为由插入内容。已有复盘与其他岗位页保持原位。
- 专岗页开头保留原始简历附件或可访问的现有简历来源入口；提供真实 JD 来源、准备日期和返回通用学生版链接。JD 截图可按需要直接上传；HR 聊天只提取面试必要信息，不复制无关联系人资料。
- 正文原生标题唯一，不重复 H1；按内容拆段，短表用于映射，示范稿用连贯口语段落。长文逐章写入并局部回读，追加时确认目标位置，避免章节倒序。
- 更新前记录版本；保护专岗页既有有效内容、附件和学生手工填写。写失败先读回判定是否已成功，不能盲目重试产生重复页、重复内容，也不能新建替代页掩盖失败。
- 不改权限、所有权，不对外发送，不将内部审计放进学生页面。用户要求仅创建 Skill 时只修改本地技能文件，不能顺便重做任何学生的飞书材料。

## 独立回读验收

写入后实际读取，而不是仅检查成功回执：

1. **位置与唯一性：** 新页 parent_node_token 必须等于已确认学生版的 node_token；同公司同职位无重复。原主页与双通用页的 URL 不变。
2. **范围保护：** 通用学生版与老师版的正文、顺序、附件／媒体和手工内容与写前一致；若其间有别人编辑导致版本变化，逐项判断变化来源，不整页回滚覆盖他人更新。
3. **正文内容：** 对照内容合同逐项覆盖；题卡、三段重点示范、案例及任务有实际正文，短轮次速读与完整底稿相互对应。只有用户限定短稿时才不按全套覆盖验收。
4. **格式与事实：** 无重复文档级标题、坏图／空媒体、错姓名、教师内部字段；新图逐张目视检查；关键事实、指标口径与来源完整。
5. **交付状态：** 必需项失败则继续在授权范围内修正；确实受阻时列出已完成、缺项和最小所需信息。不得把目录修好、8 道 HR 问答或命令成功等同于完整专岗验收。

## 最终表面视觉验收

完整专岗页使用图解时，结构读回和最终渲染缺一不可：

1. 读回每张图片／画板的非空 token 或 `src`、标题／图注、所在章节和块顺序，确认业务闭环、证据矩阵与 Case 路径没有错位或重复。
2. 将最终学生可见页面导出为 PDF，或使用能覆盖同一完整表面的等价渲染；不能只看编辑器中的源码、Mermaid 语法或 CLI 成功回执。
3. 逐页检查裁切、重叠、跨页断裂、最小字号、表格宽度、图例、图文距离和正常桌面缩放下的可读性。
4. 任一页失败时修正并重新导出，从第一页重新完成检查；不能只复查改动页。
5. 把页数、已检查页、检查项和未解决问题写入 `visual_contract.render_qa`，运行共享 manifest 校验。空媒体、缺图、缺来源、部分逐页检查或仍有问题时保持未完成状态。

通用模拟面试的全册校验器包含双端、三岗位卡等规则，不可拿它的旧页错误驱动本 Skill 重写通用材料。专岗应验证单个目标的内容、父子关系和原页保留；必要时做只读检查，但明确其检查范围。

最终给独立专岗链接、当前 revision_id、原页保留核对结果和影响使用的待确认项。不输出本地母稿，除非用户明确要求本地副本。
