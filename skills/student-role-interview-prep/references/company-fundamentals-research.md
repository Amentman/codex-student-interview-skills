# 公司基本面调研合同

真实公司专岗的公司调研不是公司百科，而是把“公司当前怎么经营”转成“这个岗位为什么存在、候选人应该怎样回答”。完整专岗准备必须有独立公司基本面模块；只在“为什么选公司”题里写一段品牌介绍或在页尾堆来源链接，不算完成。

## 最低交付结构

| 模块 | 必须回答 | 面试产物 |
| --- | --- | --- |
| 一句话定位 | 公司现在服务谁、以什么能力解决什么问题 | 30 秒公司理解，不用“大平台、发展好”代替 |
| 当前业务版图 | 最新业务分部、主要产品／服务、目标岗位可能位于哪里 | 业务地图；实际归属不明则标 `Open` |
| 价值与经营逻辑 | 用户／客户、核心任务、价值创造、可核验的收入或经营抓手 | 岗位日常和指标为什么重要 |
| 当前战略与经营信号 | 最新官方战略、产品变化、季度／年度经营信号 | 事实 → 岗位含义；数字带统计期、口径和单位 |
| 产品与业务链 | 与 JD 直接相关的用户旅程、输入输出、上下游和失败点 | 岗位处于哪一段、需要和谁协作 |
| 竞争与差异化 | 同一用户任务下的替代方案和比较维度 | 比较任务完成、质量、成本、生态、信任，不堆排名 |
| 风险与约束 | 合规、隐私、安全、质量、成本、履约或商业风险 | 主指标、护栏、回退和人工确认 |
| 面试转化 | 为什么公司、为什么岗位、分业务回答切换、反问 | 60–90 秒公司动机和 3–5 个业务反问 |
| 来源登记 | 每个关键事实的来源、发布日期、访问日期和稳定性 | 可追溯来源表；动态事实面试前复核 |

公司存在三个以上业务分部、产品层或上下游时，使用 `visual-document-delivery` 生成公司业务版图与岗位位置图。公开分部标 `Externally verified`；基于公开资料整理的链路和岗位位置标 `Inferred`；没有内部资料时必须注明“非内部组织／产品架构”。

## 来源层级与时效

按以下顺序取证，低层级不能覆盖更高层级：

1. 学生收到的官方 JD、邀约和职位页面：岗位职责、资格、业务池、职位编号。
2. 交易所／监管披露、最新季度业绩、年报：当前分部、经营口径、战略和风险。
3. 公司官网、官方产品资料、官方新闻与治理页面：产品能力、用户、发布时间和责任边界。
4. 政府、监管和行业组织原文：政策、行业定义和合规要求。
5. 可信行业／财经媒体与竞品官方资料：交叉验证和竞争视角。
6. 社区、测评、招聘镜像和论坛：只作线索，不单独支撑关键事实。

所有动态事实记录“发布／统计日期 + 本次访问日期”。最新官方季度披露与旧年报不一致时，正文采用最新口径，并说明发生了什么变化；不要把旧组织图、旧产品名或旧指标包装成当前状态。面试时间已知时，在面试前 24 小时复核职位状态、业务归属、产品名和最新经营披露；无法复核就标注资料截止日。

## 业务单元不明时怎样做

业务单元未知不阻塞完整准备，但必须分层处理：

- 先研究集团级定位、最新业务分部和共同战略。
- 再根据 JD／截图列出的业务池，比较各分支的用户、业务链、指标和风险。
- 将实际团队、内部目标、岗位 KPI、协作分工和招聘动机保留为 `Open`。
- 给出开场确认问题和按业务分支切换的回答，不替候选人选择一个“最像”的团队。

公开公司信息不能证明学生做过任何事情。公司调研与学生证据使用同一事实分类：`Confirmed`、`Externally verified`、`Inferred`、`Knowledge supplement`、`Open`。

## 从事实转成面试表达

每条进入正文的公司事实都完成以下转换：

```text
公司事实 → 对岗位的含义 → 候选人的真实证据或处理框架 → 面试回答／反问
```

例如，官方披露某业务强调履约效率，只能推出该岗位可能需要同时关注增长与履约护栏；若学生没有履约项目，只能回答分析框架，不能写成做过供应链优化。

公司动机稿必须回答：

1. 这家公司当前最值得关注的业务变化是什么；
2. 它为什么使这个岗位有价值；
3. 学生哪段真实经历能够迁移；
4. 具体业务单元或指标未知时准备怎样确认。

反问优先确认用户场景、业务目标、主指标与护栏、产品运营／算法／研发分工、新人前三个月交付；不问官网即可查到的公司规模、产品列表或口号。

## 完成门

以下任一情况存在时，公司基本面模块保持未完成：

- 没有独立公司调研章节，只有通用“为什么公司”答案；
- 只描述公司做什么，没有说明与 JD 和学生表达的关系；
- 业务分部、产品名或经营数字没有日期，或使用旧口径冒充当前；
- 实际业务单元未知却写成已确认，或把集团战略写成团队目标；
- 竞品部分只列名称、融资、排名或功能，没有统一用户任务和比较维度；
- 关键动态事实无可点击来源，或来源只有招聘镜像／媒体转述；
- 没有公司动机、分业务回答切换、业务反问和面试前复核项。

公司模块完成后，学生至少能够脱稿讲清 60 秒公司理解，并回答“为什么是这家公司、为什么是这个岗位、不同业务归属会怎样改变你的判断”。文档完成与学生已经练会分开报告。
